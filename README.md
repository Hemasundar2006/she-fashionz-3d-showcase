# SHE FASHIONZ — The Silk Rooms

A premium, responsive saree showcase with a cinematic maroon brand entrance, interactive collection sections, Three.js details, mobile swipe gestures, product previews, and bridal storytelling.

## Preview locally

Open `dist/index.html` directly, or serve the `dist` directory with any static web server.

## Project files

- `dist/index.html` — website structure and content
- `dist/style.css` — visual design and responsive layouts
- `dist/gallery.js` — carousel, product, scroll, and Three.js interactions
- `dist/assets/` — generated campaign and collection imagery
